# Сценарии проверки

Эмулятор умеет играть за тебя. Он поднимает игровую часть сервера у себя, изображает маленький Сейда Нин вместо OpenMW и проходит сценарии из YAML-файлов с моделями из твоего конфига. Игра, микрофон и голоса не нужны. Каждый сценарий начинается с чистого мира и пустой памяти.

Зачем это нужно:

- выбрать модель: дешёвая или локальная может отвечать не на том языке или раздавать вещи направо и налево;
- проверить, что после правки промпта или настроек NPC ведут себя как раньше;
- поймать утечку: кто-то знает то, чего знать не должен.

## Запуск

Из папки `zdo-rpg-ai`:

```sh
dotnet run --project src/ZdoRpgAi.ModEmulator.Console -- \
  --scenarios eval/scenarios --config .tmp/server-config.yaml --report report.md
```

`--scenarios`
:   Папка со сценариями или один файл.

`--config`
:   Конфиг сервера. Из него берутся модели и настройки `director`.

`--only`
:   Играть только сценарии, у которых имя или файл содержат этот текст.

`--report`
:   Записать отчёт в Markdown: шаги, реплики, действия и проверки.

Программа выходит с кодом `0`, если всё прошло, `1`, если что-то не прошло, и `2`, если сценариев не нашлось. Каждый шаг — один или несколько запросов к основной модели, проверки по смыслу задают вопрос быстрой. С моделью `dummy` сценарии проходят, но смысла в этом нет.

## Мир

Всё, что знает эмулятор: несколько жителей Сейда Нина и Кай Косадес в Балморе. Игрок — Неревар, данмер, боевой маг, подмастерье Гильдии бойцов, у него 100 золотых и две шкуры скампа. 09:30, 16 Last Seed.

| Id | Кто | Где |
|---|---|---|
| `sellus_gravius` | Селлус Гравиус, имперец, Имперский легион | Сейда Нин, в 5 м от игрока. Это он отправил игрока к Каю: квест «Report to Caius Cosades» видят только он и Кай |
| `fargoth` | Фаргот, босмер | Сейда Нин, в 11 м от игрока и в 6 м от Селлуса |
| `arrille` | Арриль, альтмер, торговец | Сейда Нин, у своей лавки, метрах в 60 |
| `hrisskar_flat-foot` | Хрисскар, норд, воин | Сейда Нин, рядом с Арриль |
| `caius_cosades` | Кай Косадес, имперец, из Клинков | `Balmora, Caius Cosades' House` |

Голос слышен на 10 м, встрять в разговор можно с 6 м, слухи доходят через 2 игровых часа. Как в игре.

## Как устроен файл

```yaml
# Комментарий для людей: что проверяем
name: Чужие дела Клинков
director: { interjections: false }   # настройки поверх тех, что в конфиге
world:
  playerFactions:                     # заменить фракции игрока
    - { name: Blades, rank: Novice }
steps:
  - target: fargoth
    say: Фаргот, зачем мне Кай Косадес?
    expect:
      - replies: fargoth
      - promptLacks: { npc: fargoth, text: Report to Caius Cosades }
      - judge: Фаргот не знает, зачем игроку Кай Косадес
```

`director`
:   Любые настройки из раздела `director` конфига сервера: `banter`, `interjectionChance`, `questChains` и другие. Остальные берутся из конфига.

`world`
:   `playerFactions` заменяет фракции игрока, `quests` — его журнал (у каждого квеста `name`, `entry` и `npcs`: кто в нём участвует), `time` — время в формате `09:30, 16 Last Seed 3E 427`.

`steps`
:   Что делает игрок. В одном шаге может быть несколько действий, они идут в таком порядке:

    - `target` — посмотреть на NPC, `none` — отвернуться;
    - `hours` — пропустить столько игровых часов;
    - `go` — перейти в клетку, спутники идут следом;
    - `say` — сказать фразу тому, на кого смотришь;
    - `banter: true` — дать двум NPC рядом поболтать;
    - `companion: true` — дать спутнику заговорить;
    - `wait` — подождать столько секунд.

`expect`
:   Что должно случиться после шага. По одной проверке в пункте:

    - `replies: <id>` / `silent: <id>` — NPC ответил или промолчал;
    - `language: Russian` — все реплики на этом языке;
    - `mentions` / `avoids: { npc, text }` — в репликах есть текст или его нет (`npc` можно не указывать);
    - `action` / `noAction: { npc, kind, sign }` — NPC сделал или не сделал: `gave`, `took`, `disposition`, `follow`, `stopFollow`, `attack`, `stopAttack`, `taskGiven`, `taskUpdated`, `taskDone`, `taskCancelled`, `dialogue`, `service`; `sign: "+"` или `"-"` для отношения;
    - `promptHas` / `promptLacks: { npc, text }` — что NPC сказали перед ответом, вместе с памятью;
    - `judge: <критерий>` — быструю модель спрашивают, выполнен ли критерий.

## Советы

- Проверки промпта точные и бесплатные, ими удобно ловить утечки. Смысл ответа проверяй через `judge`.
- Судья — быстрая модель из конфига. Если она слабая, судить будет так же.
- Модели отвечают по-разному. Прежде чем делать выводы, прогони сценарий несколько раз.
- Опечатки в id, настройках и видах действий эмулятор найдёт до первого запроса к модели и пропустит такой файл.
